# Security Policy

## Reporting a vulnerability

We take security seriously. If you discover a security issue, please report it
privately **before** opening a public issue.

- Open a [GitHub advisory](https://github.com/sinanalizz123-max/prayer-tracker/security/advisories/new)
- Or email the maintainers directly through the GitHub profile of the repository owner.

Please do not create a public issue that contains details of the vulnerability
until it has been addressed.

## What to include

- Affected version(s).
- A description of the vulnerability and its impact.
- Steps to reproduce, if possible.

## Response

We will acknowledge your report as soon as possible and keep you informed of the
fix timeline.
